PL5 session 7: the platform catalogue's help keys move from `ntf.*` to the help-key form `hlp.notify.*` (for example `hlp.notify.security.login_alert`), registered in the platform help registry. Message keys (`title_key`) and the `ntf.*` settings keys are unchanged. A product that links to the old help keys should use the new ones.
