PL5 session 7: `PublicPolicies.officers(packId)` reads the Grievance Officer and Data Protection Officer from the pack's policy set parameters (`grievance_officer`, `grievance_email`, `grievance_address`, `dpo_name`, `dpo_email`), so a site's footer shows the officers from the policy set and never from code.
