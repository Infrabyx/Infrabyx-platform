`@infrabyx/connectors/pdf`: the `pdf-text` adapter (`PdfTextExtractor`, PR-LDC-39), a bounded PDF text parser with no dependency (cross-reference tables and streams, object streams, FlateDecode, ToUnicode), run in a worker thread with heap, stack and time limits; refuses unscanned, infected, changed and encrypted files and anything over a limit.
