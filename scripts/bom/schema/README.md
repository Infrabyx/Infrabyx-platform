# CycloneDX 1.6 JSON schemas (vendored)

`bom-1.6.schema.json`, `spdx.schema.json` and `jsf-0.82.schema.json` are copied unchanged from the
CycloneDX specification, tag `1.6` (github.com/CycloneDX/specification, `schema/`), under the
Apache License 2.0 in `LICENSE`. `scripts/bom.mjs` validates every BOM against them offline.
