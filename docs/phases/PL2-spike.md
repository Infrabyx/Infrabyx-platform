## Notes on the build environment

- From the build sandbox, GHCR blob downloads and quay.io are blocked. ECR Public answered "Data limit exceeded" for an anonymous pull. Docker Hub works, so test images are pinned by digest from Docker Hub (`infra/docker/TEST_IMAGES.md`). GitHub-hosted runners can still pull from GHCR and quay.io, so Keycloak, Zitadel and OpenFGA keep their upstream registries in CI.
- The scripts and outputs of this spike are not committed. They exercised vendor SDKs outside `packages/connectors`, which is allowed only for a throwaway spike; the real adapters come in their sessions.
