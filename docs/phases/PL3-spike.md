**Date:** 2026-10-27 · **Decision:** PL3-D-15 (`[ASSUMED – owner review]`) · **Plan:** `docs/phases/PL3-plan.md` §12, session 1

This spike covers the [VERIFY] items of the PL3 plan. Vendor documentation hosts are blocked from the build sandbox, as in PL2 (PL2-D-64). The facts below come from three sources:

- the npm registry (versions, publish times, licences, dependencies);
- the published packages, installed and run on Node 24.22.1;

## What this changes in the plan

- **RULES:** none. ZEN stays the reference, pinned to 2.1.7.
- **CEL:** `rules.cel.max_cost` keeps the default of 10 000 (A-11). Its meaning is now precise: the maximum number of AST nodes in an expression.
- **PUSH:** neither adapter imports a vendor SDK. Both are thin `fetch` clients, so `vendor-import` has nothing new to allow.
- **ESIGN:** inbound webhooks never change state by themselves. The plan's `verifyWebhook` becomes `handleWebhook`, which parses the event, reads the status back from the vendor and returns the verified state.
- **XLSX:** none in PL3.
